# 🩺 Vitalis-beta – Personalized Health & Fitness Recommendation System

## 📌 Overview
Vitalis is a full-stack web application that provides personalized health, diet, and fitness recommendations based on user vitals, lifestyle, and goals.

It uses a rule-based system to generate explainable and practical suggestions.

---

## ⚙️ Tech Stack

- 🎨 Frontend: React.js, CSS
- ⚙️ Backend: Node.js, Express.js
- 🧠 Logic: Rule-Based Recommendation Engine
- 🌐 APIs: Weather API

---

## 🚀 Features

- 🎯 Goal-Based Health Tracking  
- 🥗 Diet Recommendations (BMR, TDEE based)  
- 📊 Progress & Adherence Tracking  
- 🔥 Daily Challenges & Streak System  
- 🌦️ Weather-Based Suggestions  
- 🧠 Explainable Rule-Based AI Logic  

---

## 🧠 Core Working

The system works using a **rule-based engine**:

- User inputs vitals (age, weight, sleep, activity, diet)
- Backend processes data
- Rules are applied (IF–THEN logic)
- Personalized recommendations are generated

Example:
- BMI > 25 → Suggest calorie deficit  
- Low sleep → Recommend recovery  
- Sedentary → Suggest exercise  

---

## 🔄 Workflow

User Input → Backend Processing → Rule Evaluation → Recommendations → UI Display
